## **Welcome to QuickFlicks!**

It's like NYT Connections, but for movie lovers! This is a silly React & Node.js web-app built by 3 [Penn Spark](https://pennspark.org/) members, featuring a movie-themed mini-game inspired by NYT Connections, and a search catalog connected to IMDb API.
